# 2026-06-19 Refactor Progress

## Completed in this pass

- Replaced the brittle implicit queue/status model with explicit `DownloadJob` records.
- Preserved `/api/status` for the current React UI while adding structured `/api/jobs`, `/api/instances`, and `/api/health` endpoints.
- Made payload preparation synchronous so codesigning completes before Spotify instances start.
- Fixed remote debugging port collisions by assigning one port per instance.
- Added a real `ping -> pong` handshake requirement before marking an instance ready.
- Added idle-instance watchdog recycling.
- Added bounded job attempts and failure states.
- Added WAV validation: RIFF/WAVE/data header checks, byte-size checks, short sample-window RMS/peak/silence checks, and ffprobe status.
- Added MP3 transcode validation and WAV fallback.
- Added JSON sidecars for completed outputs.
- Added range-capable completed-file serving through `/api/stream` and `/api/file`.
- Rewrote `setup.sh` to be safe and flag-driven; it no longer deletes `/Applications/Spotify.app`.
- Added `scripts/doctor.ts` for environment/workspace diagnostics.
- Added active architecture and known-failure docs.
- Added payload IPC `get_metrics` support and StateManager metric accessors.

## Not completed yet

- `Main.mm` has not yet been physically split into multiple Objective-C++ files.
- Payload audio-source arbitration is not implemented yet; duplicate writes remain possible.
- IPC is not fully JSON/protocol-versioned yet.
- The React UI has not yet been upgraded to visualize `/api/jobs` and `/api/instances` directly.
- No real macOS runtime verification was possible in this environment.
- Bun dependencies were not installed here, so full Bun typecheck/build could not be executed.

## Recommended next iteration

1. Split `Main.mm` into `Entry.mm`, `IPC/Server.mm`, `Hooks/AppHooks.mm`, `Hooks/AudioHooks.mm`, and `Audio/CaptureController.mm`.
2. Add a payload-side `CaptureSource` arbiter that chooses one audio source per track.
3. Convert all IPC commands to JSON request/response messages with protocol versioning.
4. Add React panels for health, instances, job logs, and validation warnings.

6. Run `./setup.sh --rebuild`, `bun run scripts/doctor.ts`, and live capture tests on macOS.
